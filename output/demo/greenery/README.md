# 全镇绿化：本机实录

原版低饱和灰绿/橄榄绿、暖褐树干和灰雾气氛保持。217棵原树换成立体模型；3树、2灌木、3草、3花共11种变体，6014组小植物、约56239平方米草地。布置覆盖主街、住宅区/院落、北边果园、车站外围、牛奶店周边和广场，不包括邻镇街区。

## 来源与构建

原创Blender套件在 assets/source/greenery/，三档树木LOD、两档小植物LOD及打包调色板保留可编辑。生成器 tools/build_greenery.py / tools/plan_greenery.py；Unity共享入口 GreeneryAuthoring，6014组小植物以分区实例复用网格。25个源网格重新打开检查通过，花叶朝上法线已验证。

本目录图片和短片来自Unity 6000.3.18f1 / macOS Metal / Apple M5 Pro实际渲染的窗口；不是概念图。图中的机位由程序分区摆放，并以真实控制器做短距离侧移。full-town-overview 是升高相机、临时去雾的布局检查，远处细小植物按正常距离剔除；不可当作全部细节鸟瞰。

视频由六段原生画面与游戏AudioListener原声按真实时间顺序串接，每段之间切换机位；没有生成帧或配音、没有加速。
