# 牛奶店与雨天路灯实录

这份约37秒视频来自更新后的原生Mac游戏：前段在店内看送奶少年、关闭/打开两扇木门并步行进出，后段对比雨天亮灯与晴天熄灯。雨声是实际AudioListener的立体声混音，没有后配。

为了直接比较，录像使用隔离测试存档暂设正午雨天，末段切换晴天；正常游戏仍按照已确认的每日阵雨表渐变循环。实际1280×720画面按真实时间戳编码30fps，录制采样约20Hz，不代表游戏帧率。使用程序驱动真实角色控制器、碰撞与交互射线，非物理键盘鼠标或玩家盲测。正常存档未使用。

`牛奶店与雨天路灯实录.mp4`拼接两段原速录制；两份独立片段、柜台少年与门/路灯截图也在此目录。`recording-provenance.json`包含源文件、时长、音频格式与校验信息。

操作：靠近任一木门并看向门扇，按E打开／关闭。站在门扇转动范围内时会提示先让开。两个门叶分别记忆开关状态。路灯自然亮度低于42%时全亮，高于60%时关闭，中间平滑渐变。
