# 灰雾与重雨：Mac 实机录像

- `天气效果实录.mp4`：约41秒合辑，依次为落地水花、走进室内听雨、灰雾街景。
- `01-大雨与落地水花.mp4`：约30秒，保留连续雨声，跨过真实音频循环接缝。
- `02-走进室内听雨.mp4`：约19秒，真实控制器进屋、转向窗外、出屋，包含最终游戏混音。
- `03-灰雾白天.mp4`：约10秒，13:05普通日程下的平视街景。

1280×720实际Unity/Metal画面，按真实采集时间戳编码为30fps视频，没有变速、调色或后配雨声。录屏采样约20fps，不代表游戏帧率。前两段在隔离的验收存档中固定雨天预设，以便完整比较声音；时钟正常推进。第三段采用已确认的日程。脚本驱动真实控制器和视角，不是物理键鼠或陌生玩家盲测。正常存档保持完整。

实现保留256条雨线，新增一张96落点的水花网格；地面查询缓存，每帧最多4次。三层原创合成循环分别为24/29/31秒，移除旧六秒循环两端归零。进屋时雨声低通平滑到1100Hz，落地层到750Hz，叠加屋顶闷雨声。参考Unity官方AudioLowPassFilter接口： https://docs.unity.com/en-us/engine/6000.3/script-reference/unityengine/audiolowpassfilter 。

完整来源、时长及视频摘要见 `recording-provenance.json`。回归检查与正常存档保护见 `builds/macos-current/verification-fog-rain-street-video-20261010/acceptance.json`。首轮使用滤波前声源取样，室内频谱断言失败；改为最终AudioListener混音后通过，原始失败记录保留，没有修改游戏滤波来放宽断言。
