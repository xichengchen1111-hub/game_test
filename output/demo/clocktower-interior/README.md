# 钟楼内装、落灰与蛛网：2026-10-09 实机记录

用户要求为当前 20 米钟楼增加砖石墙地、从底到顶逐渐明显的积灰与同一串脚印、上层蛛网及少量浮尘。内墙为约 0.38×0.18m 的浅色砖纹，底层铺约 0.58×0.38m 的旧石板；原木梯和平台保留。8 档灰尘材质只改变同 87 个原位脚印的对比与破边。上层 3 处墙角、3 处扶手外侧有锚定蛛网，机房浮尘上限 32 枚、实测约 20 枚。

本目录图片全部是实际 Mac/Metal 播放器画面。`tower-dust-gradient-lower/middle/upper.png` 是沿实际楼梯到达第 7／47／87 段后，以相同方位和普通眼高拍摄的对比；`tower-ground-stone-and-wall.png` 显示底层石板与砖墙，`tower-upper-corner-cobwebs.png` 与下一帧显示上层角落和浮尘。另保留 720p 的顶部画面。

`results.json` 四项通过：两档分辨率完整上楼、独立进程机房读档并逐级下楼、中层存档。首轮全部通过后，最后仅柔化脚印材质并增加底层拍摄，重新构建并复跑两档完整 101 点上楼、门/护栏/双钟/装饰检查；保存逻辑及几何未变。最终真实粒子读数、位移匹配与材质对比在 `clocktower-results.json`；没有通过强制发射粒子或跳过行走制造结果。
