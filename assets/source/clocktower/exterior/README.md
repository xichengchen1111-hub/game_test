# 青川古钟塔：图像参考重建

这是依据用户批准的 `../reference-approved-v3.png` 在本地 Blender 中重建的可编辑三维资产，沿用牛奶店的参考图建模流程。2026-10-09 用户在实际游戏中接受此钟楼为基础后，要求加高为约 20m、三层体量；当前版本按该新要求重新安排立面、砖层和楼层，而不是缩放旧模型。没有向 Meshy 上传图片、调用其服务或使用其推理结果。网格、雕饰、砖石／石板材质和法线均由本项目制作脚本生成；参考图只约束造型和色彩，不投影成照片平面。

## 文件

- `ClockTower1931.blend`：完整可编辑模型；`ClockTower1931_Export` 为七个材质合并的正式外观网格，`Review_Only_UnityOverlays` 为仅供预览的门、钟面、指针、铭牌、灯光和场地。
- `ClockTower1931.fbx`：与 `game/Assets/Art/ClockTower1931/ClockTower1931.fbx` 一致的正式导出；包含七个定位标记，无相机、灯光、钟面文字、指针、门扇、铭牌或碰撞体。
- `textures/`：1024² 原生砖砌、奶油石材和灰蓝石板 BaseColor／Normal，共六张 PNG。统一维护的米白砖面没有红砖露底、剥落或夸张污迹。
- `manifest.json`：尺寸、坐标、材料／贴图名称、来源和建模解释。
- `previews/`：前面、背面、钟圈细节、入口细节的 Blender 渲染。不是 Unity 实机截图；其中门、钟面和铭牌仅是对应游戏叠加内容的示意。
- `verification/inspection-results.json`：重新打开保存后的 `.blend` 与导出 FBX 的实际检查结果。

## 复现

使用 Blender 4.5.9 LTS，在仓库根目录运行 `tools/clocktower/build_exterior.py`。脚本直接读取 `game/Assets/Scripts/ClockTowerInteriorLayout.cs` 的高度、中层／机房地面、墙顶、钟心和钟盘直径常量，尺寸不符合本轮契约时会在写输出前停止。入口为后台 Blender，先给 `--python-exit-code 1`，再给 `--python` 脚本参数。生成脚本清空其新建 Blender 会话后重新生成这套资产，不修改其他游戏资产。

随后运行此目录的 `verification/inspect_model.py`。它重新打开保存后的 `.blend`，检查网格原点、UV、非零面积、总体高度、30 条实际外壳门洞射线，再在干净场景导入 FBX 检查米制和方向标记。`normalize_export.py` 是首次生成后修正合并网格残留局部旋转的一次性记录；相同修正已纳入主生成脚本，正常重建不必另跑它。

## 布局契约

Blender 使用 X 右、负 Y 南门、Z 高。FBX 以 `-Z` forward、`Y` up 导出；Unity 应根据 `FrontMarker` 与 `EastMarker` 校正，而不是只凭外观猜轴。物理外宽 3.60m，内净宽 3.05m，总高 20.00m；屋檐最大外包围为 X/Y ±2.107m。南门净宽 1.10m，地面 0.12m，净门头 2.27m，固定木拱帽完全在门头之上。门框、基座、铭牌仍是原来的人尺度，不随塔高放大。

三段完整立面分别对应地面旋梯段、中层平台与上部机房：地面 0.12m，中层 8.530435m，机房 15.00m，两道完整围塔线脚与中层／机房地面精确相齐。四面钟心高度 16.72m，钟盘直径 2.20m，游戏钟面距中心仍为 1.86m，外壳钟圈净内径 2.210m。内墙顶 18.30m；四坡瓦顶与尖饰补足至 20.00m。

每个下层四面各有一组实体背板的拱形闭百叶，共八组。它们服务于同一个旋梯空间，不是可看穿窗户或额外房间。砖贴图依然是每块 0.36 × 0.144m、每张 1.44m 重复单位，增加真实角石层数与纹理重复次数。门拱、叶饰、瓦片保持既有尺度。

Unity 继续提供同一几何坐标下的内衬墙、碰撞、旋梯、机芯、活动门、精确罗马钟面／动态指针及墙面历史牌。此 FBX 仅负责外饰层；不要给导出的每片瓦或雕花添加自动碰撞。

旧 9.5m 版本的源文件、导入资源、生成脚本及验证证据已完整复制到仓库忽略目录 `builds/clocktower-20m/previous-art/`，保留可恢复版本。当前源目录中的旧 `build.log`／`normalize.log` 仅为首次 9.5m 制作的历史记录，不是 20m 验证结果。
