## 进入游戏前的实际检查

- 实际导出的 Tripo idle、walk、talk 全段与各自闭环接缝，分别查看正面、左右侧面、斜后方；手指、袖口、腰带、下摆、裙摆均需清楚可见。
- 检查 idle↔walk、idle↔talk、walk↔talk 的插值过渡，不能只审两张静态渲染。人物退让／步行另看摆臂，律师另外检查上车与驾驶姿势。
- 若仍有穿插，在可编辑源中修网格／权重／动作；不能靠放大碰撞盒、把手臂永久撑开或隐藏问题角度通过。
- 站立尺寸、骨骼、脚底与闭环数值检查不能证明自穿插通过。旧转换工具只固定下肢、从 idle 追加轻微头胸动作；用户追加真正行走／对话后已改为导入三条实际源动作。最终必须使用实际源动作，保留髋腿运动和原皮肤权重，数值检查仍不能证明无自穿插。
- 源模型通过后再在实际警署灯光、玩家视距和完整第一幕流程中静音检查。记录实际检查的资源哈希与证据，才在 `../acceptance.json` 中启用对应角色；二维参考获认可不等于三维已获认可。
