# B 车站与「墨绿与黄铜」列车

2026-10-10，依据用户确认的 B 铁玻璃车站及列车方案制作。它们是可编辑的原创低模资产与实际游戏交互，概念图另保留在 `docs/concepts/`。

## 游戏流程

从青川镇东端 B17 南门进入候车厅，穿过后门与坡道到一号站台。靠站台一侧的车门停靠时开启；通过三个21cm踏步实际登车。两节客车的门厅、中央过道和连接通道可以连续行走。

客车01前部南侧窗边座位有 `E 坐下并出发` 提示。落座后关闭车门、鸣笛、放汽，车轮及连杆转动，列车向东短距离启动，窗外站台随之移动。约5秒后渐黑1秒，加载下一城镇并从同一座位渐显。到站按 E 起身下车，能探索邻镇车站街区，或再次坐下返回青川。坐着可以转头，不能行走；到站后仍可查看怀表、调查簿和暂停菜单。

黑屏加载不规定案件中的班次或车程。发车及转场暂停现有共享游戏时钟，站台漫步与到站停留按原有速度计时。车站实体钟读取怀表同一时钟；钟楼原有偏移仍独立保留。

## 资产与尺寸

- 候车厅30×12m，两翼各8×8m；主入口仍为地图坐标(188,40)，后门(188,52)。雨棚68×22m，使用既有北侧铁路用地，圆弧铁架和透明玻璃均为实体模型。站台顶高0.42m。
- 列车包含2-6-0蒸汽机车、独立煤水车、两节15m客车、短行李车。客车宽2.9m、地板顶高1.05m，窗与门实际开孔，中央过道约0.8m。
- 车站、车厢的内外空间来自同一FBX，实体碰撞使用同一网格，玻璃不作为不透明碰撞背板。车门、车轮、连杆保留独立枢轴；场景共用 `RailTrain.prefab`。
- `assets/source/rail/StationB.blend`、`TrainSet.blend` 是可编辑源；`tools/rail/build_rail_assets.py` 为最终生成器。Antigravity负责隔离目录中的建模初稿；实际开口、轮组父级变换、房顶、字牌与钟面经过本地复核和修正。源渲染仅是Blender检查图，游戏截图另存。
- 灯光绑定现有昼夜系统，无新增阴影点光源。列车两节车厢的雨遮蔽随位移重新登记；新屋顶明确记录山墙方向、圆弧/椭圆剖面。既有建筑保留默认屋顶算法。

发车前写入停靠状态与座位检查点，移动和加载期间不以临时坐标覆盖它。到站后写入目的场景、座位状态、累计乘车次数，保留调查簿、已打开设施、对话、塔钟调整与累计时间。重启可恢复本镇或邻镇的座位，按 E 起身；中途检查点恢复到出发站的停靠列车。测试仅使用独立 `rail-review-save.json`，不改正常 `slice-save.json`。

邻镇目前是120×110m的可步行车站街区：站台、小候车站房、街道和环境店屋，支持下车与返回。它不是完整第二座城镇；环境店屋是外景占位，没有擅自实现问路证人、坏灯、电话、棋社或历史路线。青川现有四处成品建筑，其余仍按原有占位范围保留。

## 重建与验证

仓库根目录运行 `tools/BuildRail.ps1` 重建源资产、支持图片/声音和Windows播放器；`-AssetsOnly` 只生成资产。地图修改仍先运行 `python -X utf8 tools/check_town_map.py --write`。游戏构建使用安装的 Unity 6000.3.18f1、URP17，Blender为5.2 LTS。

`tools/ReviewRail.ps1` 提供双向乘车、座位重载、中途退出、邻镇检查点与其重载模式。初版结果见 [铁路验收](../output/demo/rail/README.md)，本轮细化与车票结果见 [细化验收](../output/demo/rail-polish/README.md)。EditMode覆盖真实网格的开窗/过道/顶面、错误位移、实心窗背板、额外开口、屋顶剖面和票孔；原生播放器检查走动、3m交互射线、场景切换与持久化。它们不是物理键鼠测试、陌生玩家盲测或低配帧率基准。
