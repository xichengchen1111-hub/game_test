## 坐标与范围

- 钟楼中心 (0,0)，东 +X、北 +Z，单位米；边界 X[-170,240]、Z[-155,122]，约410×277m。
- `rect=[中心X,中心Z,宽,深]`；`point/door=[X,Z]`。建筑主体与附翼组成实际轮廓，宅地包括院子；不得用宅地尺寸造房屋。
- 70块宅地、209棵树，主体有连排、双拼、退院、L形附翼、十字形公共建筑。树的r为树冠投影半径，不能当作树干或实机碰撞尺寸。
- 道路数据区分车行面、净人行道和设施带；院落与后巷通道单独记录。路线演算沿公共道路中心线抽象，尚非实际人行道导航或全宽碰撞验收。
- B编号为命名地点，包含环境和候选地点；H编号为背景住宅/商住，无新增证据。未知层高与室内布局不能凭平面图认定已完成。

## 两天行程与范围限制

- **19日实际**：本镇车站 → 列车 → 另一镇 → 问路。另一镇不制图，无虚构坐标、车程、班次或返程。问路点、坏灯、店主与相关巡警归另一镇。本镇B14杂货铺/B15教堂只是环境；电话与棋社所属城镇待确认，不能把候选设施播放成既定19日历史路线。
- **20日陈述**：挪用了19日的真实跨镇经历；与20日在本镇露面、返家、接奶等实际事件分开。20日未验车票只削弱当天行程说法，不推翻19日实际乘车。
- **本镇去站返家**：639.15m，1.2m/s下8.88分钟；17:35—17:55窗口剩余11.12分钟未分配，不等于证实他在站内等了这么久。
- **接奶**：前户H66→主角家→后户H37，步行2.86分钟；十分钟签收窗口剩余7.14分钟容纳交付和停留。两户位置、东门和17:56动画时刻是演算提案。
- **两宅关系**：主角东正门(-16.5,-57)，西厨房门(-32.5,-57)，邻居观察窗(-41,-57)。40m绕屋路与25m邻居陪同通道；二维检查为指定观察点，不是所有人都看不到。
- **仍未闭合**：19日交通及电话/棋社位置；20日候车交通、18:35离馆后至20:40；情夫异地行程；室内、3D视线与钟面可读性；煤车转弯及占道。不要据此声称全部角色完全合理或已验证不在场证明。

```sh

python3 tools/check_town_map.py
```
