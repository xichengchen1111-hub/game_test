WHAT CHANGED

这次重新设计的是街区关系

第一版把相同房屋稀疏摆在大块空地里。这版把中心区收紧到 410×277 米的设计范围，形成细长宅地和连续街面；保留 17 处命名建筑（含环境与候选地点），加入 53 处环境住宅／商住宅地。新增背景不承担证据或任务。

房屋占地与宅地分开记录：住宅可以共墙、双拼，也可以退后留前院；L 形后翼用于厨房或作坊。院子有菜畦、晾晒、储物和后勤用途。后巷连接宅地背面，前门朝向街道。

STREET SECTION

树有位置，人也有通道

车站路 12m = 两侧各 1m 树池设施带 + 各 2m 净人行道 + 6m 车行面。住宅街 12m = 两侧各 1.5m 设施带 + 各 2m 净人行道 + 5m 车行面。

后巷净宽 3m，院内主步道 1.4m、后院小径 1m。圆形绿色线是成年树冠投影，中心小点才是树干；树干避开入口，树冠可遮荫。图上的树种与树龄尚未锁定。

没有添加现代停车场或现代道路标线。道路宽度为游戏设计尺度，未作为现实工程规范使用。

REAL TOWN REFERENCES

参考真实小镇的生长方式

Dorset 官方：Bridport Historic Towns Survey：借鉴连续沿街建筑、后部细长宅地、垂直小通道与后巷，以及商住和作坊混合的结构。道路网络与坐标为原创提案，没有复制当地地图。

Historic England：历史菜园与果园：用于理解住宅外围的小块生产性绿地。因此外缘空地被明确为菜园、果园、农田和铁路用地。

这些是形态参考，不把青川镇设定成真实英国城镇，也不把本设计称为历史测绘复原。

BOUNDARY & FILES

本轮修订与仍待确定的事项

撤回为凑时长而延伸的300m站路，车站恢复本镇东缘（188,46）。19日丈夫由本镇车站乘车到另一镇问路，20日挪用前一天行程；此图仅含本镇；新增邻镇游戏街区不代表19日历史路线。本镇杂货铺与教堂不再代表问路场景。主角住宅改为东正门、西厨房门，补南侧绕屋通道和东侧后巷返家路径。邻居新增对应侧窗，接奶点到钟楼保留视线通廊。电话亭、候车点和唯一煤车卸货点已落位，均属于本版设计提案。

第四版已接入 Unity，B17 现为完成的铁玻璃车站。钟楼、钟表铺、牛奶屋与车站可进入，其余房屋仍是环境占位；站台及雨棚使用北侧铁路用地。尚未绘制所有房间或复核完整人物视线。

上一版路线距离、行走时间和视线结果全部停止沿用。本版已经重跑本镇路线。跨镇车程、班次、电话与棋社所属城镇仍未定，不用本镇步行时间填补。
