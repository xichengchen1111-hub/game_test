# 错日证词：自由探索 MVP

本方案承接《错日证词》修订稿，按最新约定改为第一人称 3D。核心是玩家自行走访、观察和交叉核实。预计初次试玩 20–30 分钟，时长是测试目标，没有倒计时或规定访问顺序。

## 体验与完成边界

玩家魂穿到丈夫身上，不知道原主做过什么，起初试图查清自己为何被怀疑。短开场交代案件并提供已有口供和材料副本，随后立即开放小镇。完整 MVP 的车站、钟表铺和住宅三个剧情室内从开始就可访问；新增钟楼内部属于 Town 中的连续空间，同样不设解锁条件。2026-10-08 用户选定 A / WALNUT HERITAGE 钟表铺：该店采用可开关实体木门，玩家直接走入走出，不再黑屏转场；透明窗户两侧看到同一套真实空间。其他尚未制作的室内仍按原计划，未在本轮实现。

Demo 的核心收束是：玩家有依据地指出送奶证词的时刻需要校正，且丈夫把前一天的问路放进了案发日的陈述。车票与现场疑点提供其他入口，但不能独自证明丈夫杀人。完整谋杀重建和双结局留给后续章节。

玩家随时可以整理并提交阶段报告，也可以继续查。两项核心判断均有可核验材料支撑时，报告进入“需要重新调查”的收束；不足时保留具体已知事实和未解决的问题，不自动公布凶手。收束后仍可返回探索。

## 四个场景，五名人物

| 场景 | 空间与人物 | 可以先从这里发现什么 |
| --- | --- | --- |
| 小镇外景 | 广场、可直接进入的古钟楼、三处门口、一条住宅近路；送奶少年、邻居、陪伴角色 | 街钟与怀表差异、钟楼积灰中的脚印、送奶说法和派送记录；广场资料桌提供案卷摘要 |
| 车站 | 一个可走动的售票厅；售票员 | 正常验过的车票；巡警值班桌上已获许可查阅的原簿副本 |
| 钟表铺 | 前堂和小维修间；钟表匠 | 另一镇修灯通知副本，能核对问路片段中的坏灯和白布 |
| 住宅 | 连通的会客室、厨房兼书桌，门窗都可观察 | 完整车票、残信相关材料、家人的生活痕迹 |

牛奶站、棋社、警署、旅馆、医院暂不建独立场景。必要的现有记录通过有出处的案卷副本和街边人物提供。住宅的查阅许可在开场交代，不能依赖另一座未制作的建筑解锁。

第一人称观察要清楚呈现钟面、票边、日期和纸面出处。关键证物可放大并反复阅读；街钟和怀表须共用同一个连续游戏时钟，四面塔钟初始及复位后均比怀表快 30 分钟；玩家可在机芯处调整共同偏移量，避免独立计时器制造意外差值。

共 10 个证物条目：案卷摘要、完整车票、已验车票、送奶证言、派送簿、双钟观察、修灯通知、巡警原簿副本、残信裁余片、家书。家书提前呈现妻子关心孩子的一面，沿用原稿护士提到的苹果细节，不把全部对话写成对死者的指责。

## 玩家推进，陪伴角色偶尔说话

任何地点都不以“先去另一个地点”作为进入条件。物件和人物随时可以再次检查。新问法根据已掌握的材料重新计算，拿取顺序不会改变事实；必要材料可以在首次访问时取得，不要求等待提醒对白。

陪伴角色只在玩家查看某件东西后偶尔随口搭一句，例如“这张票倒是保存得挺好。”每条最多自动说一次，不打断操作、不自动总结、不发布任务，也不承担律师式带路或审批职责；开场已经授予的查阅许可不由陪伴角色逐项解锁。

调查簿记录来源、原话和玩家选取的关联。玩家自己选择要质疑的陈述，并把材料卡放到“时刻 / 日期 / 行程”的对应判断中。系统只核对所提交的关系是否有材料支持，不因收齐卡片而自动生成答案，不在物件上标注真伪。

保留最多四个短往事片段：问路、收预约信、送奶、车站露面。它们是已发生事件的导演镜头，先后次序未定；可回看和手动重排。核心可核验事实也必须存在于记录和证言中，不能靠穷举片段顺序解锁唯一答案。无需制作杀人动作、复杂表情或新建棋社场景。

## 画风和实现

环境沿用现有低模概念图：宽色块、灰蓝和紫灰暗部、暖黄室内灯光。2026-10-08 用户指定 Meshy `The Little Messenger` 替换送奶少年，保留完整儿童模型、原始服装与贴图，循环短呼吸及环顾待机；它取代此前 Toon Boy 的具体外观与握带静态方案。同日指定 `The Watchmaker’s Focus` 替换钟表铺老板：使用包中的 `Sit_Cross_Legged`，全程坐在配套木椅上修表，走跑动作只保留为资源，不进入当前行为。其他人物暂保留简化风格。参考图中的生活感由招牌、窗光、布料色块和少量日用品表达；1931 年道具保持时代一致。建模采用共用墙体、门窗、桌柜和简化人体；NPC 固定点位，先做待机与交谈动作。证物文字、日期和钟面由程序或排版制作，不能直接使用生成图里不可控的字。

使用 Unity 6000.3.18f1 和 URP；Mac 资产环境为 Blender 4.5.9 LTS，本轮 Windows 钟表铺使用 Blender 5.2.0 LTS。Unity 项目位于 `game/`；剧情与证物数据有稳定 ID。当前运行结构为常驻 Systems 加 Town，钟表铺内外就在 Town 的同一建筑中，实体门开关后直接行走；旧 ClockShop 场景仅用于共用布局检查，旧室内存档加载时映射为 Town 世界坐标，保留证物和对白状态。

所有可进入建筑的内外必须统一：共用建筑布局与 Prefab，门窗数量、位置、尺寸、朝向，建筑轮廓、楼层、屋顶和可见陈设保持对应。外部不能添加没有实际对应空间的窗户或楼层。钟表铺的窗户透视同一 Town 中的真实室内外几何；其他将来的独立室内若沿用原计划，窗景须按共用布局映射。构建检查拒绝不一致，实机验收同时查看内外并测试每个门窗。

MVP 系统：第一人称移动、E 互动、共享连续时间与 Q 怀表、Tab 调查簿、证物放大、固定分支对话、短片段回看与排序、阶段报告、存档读取。打开界面时暂停移动并正确恢复鼠标；连续按门不能重复加载。先不加入战斗、经济模拟、昼夜排班、复杂跟随、完整配音和运行时生成对话。

2026-10-08 用户最初选定第二款「电影字幕」，随后要求进一步缩小并提高透明度。当前送奶少年的底栏仅在屏幕底部约两成至四分之一处绘制淡渐变，文字有轻微阴影；有选项时左侧原话、右侧两列选项，去掉表格式长分隔线。选项仅用对应数字键（1、2、3……）或鼠标整行点击；已问与未问外观一致。无选项时原话横向铺开，点击屏幕右下半区即可推进，箭头只作提示；H回看、Esc退出按钮区域不触发推进，回看或选项界面也不触发大区域推进；保留Enter/空格。交谈暂停移动和视角，退出后恢复。用户明确恢复开场「您是住在［街名］［门牌号］的［姓氏］先生吧？」及「您太太的事……我听说了。我很抱歉。」；街名/门牌/姓氏暂按用户原句保留占位，未经确认不得自行替换。用 `milkboyGreetingRevision` 区分新版开场，旧存档下次交谈重新展示这两句，保留全部证物；看到慰问后记住版本，后续可直接回访话题。保留手套细节和反复问话，E04在说到亲手交奶、18:25和街钟依据后记录；打招呼或只聊日常不提前授予证言，已有E04保留。文本和分支来自 `game/Assets/Resources/MilkboyDialogue.json`。E05问题按当前证物重算，但本切片尚未制作派送簿交互；测试注入E05不代表已实现派送簿。
