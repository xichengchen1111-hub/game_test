## 剧情边界（全部物件共用）

- **不加时间来源**：没有钟面、刻度表盘、收信时间牌、营业时间、时刻表；火警柱不写箱号数字，防止被读成日期。
- **不加证据或路线**：不进证据合同、调查簿、证词与推理；可选的 E 查看只给一句环境描述。废纸篓只放落叶不放纸，海报全是无日期的虚构商品，小启事正文不可读。饮马槽、拴马桩不放马，不暗示送奶或任何人的出行方式。擦鞋摊无人看守，不新增证人。
- **避开剧情空间**：不进 S01 接奶点看钟通廊、S02/S03 两宅视线、F01 电话亭、F04 煤车卸货位、旅馆车位与车道、开场剧情车路线的车行面；B12、B05 门前不放新物件。人行道保留 ≥1.2 m 净宽。
- **灯光预算**：唯一发光的是火警柱红灯罩，只做随同一感光曲线的发光面，不加点光、不占 12 处光池、不加阴影灯。

故意没选（见 `design-plan.json` 的 `rejectedForStory`）：街钟（新时间来源，需用户决定）、报亭（报纸带日期）、新电话亭（已有 F01、通话城镇未定）、路名牌（街名未定）、加油泵（暗示驾车离镇）、奶罐台（牵涉送奶窗口）、公告栏与班车站牌（日期／时刻）、投币体重秤（表盘像钟）。备选：空自行车架、路口交通蘑菇灯（需先核对行车路线）。

06 海报柱偏欧式：地图注明参照英式老镇、街道设施按 1930 美国城市手册，两者在本镇并存；想更纯美式可只做一根，或改放车站前庭。

## 制作方法与复现

不是 ImageGen 图：每件都在 Blender 5.2 里用脚本程序建模，Cycles 渲染。街景小场景直接用游戏现有的 `PeriodConcrete`／`KerbStone`／`PeriodAsphalt` 贴图，阴天弱主光加淡雾，接近游戏里的灰调。海报与珐琅牌是原创 Pillow 贴图。

```
python make_concept_textures.py <tex_dir>
blender.exe --background --factory-startup --python-exit-code 1 --python render_street_items.py -- <tex_dir> <render_dir> 192
python make_board.py <render_dir> .
```

渲染 PNG 留在仓库外，仓库里只有 JPG。这些是概念渲染，**不是游戏资产**：正式制作要按游戏低多边形预算重建、加碰撞与 LOD，并在 Unity 实际光照、雨湿和夜景下检查。尺寸、碰撞和坐标都是提案，落位前要过 `build_plan.py`、`check_town_map.py` 和路线核对。
