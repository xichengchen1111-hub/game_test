# 《错日证词》旅馆五案

本轮按用户要求提供五套旅馆建筑与美术概念。每套展示外观、登记大堂、餐厅、一层空间及二层客房示意。以现有 B08 约 41×40m 宅地、两层旅馆与朝街接送车院为尺度参考，具体形体是待选择的改造提案。

| 方案 | 名称 | 建筑与氛围 |
| --- | --- | --- |
| A | 山墙老客栈 | 不等高山墙、深色木构、奶白填墙、低梁暖灯与生活旧物。 |
| B | 奶白新式旅馆 | 两层几何体块、圆角入口、阶梯女儿墙、灰绿窗框与克制的黄铜细节。 |
| C | 红砖铁路旅舍 | 横向两层红砖楼、低坡屋顶、铁雨棚与侧接餐厅，面向旅客的朴素秩序。 |
| D | 石院回廊旅馆 | U形两层围合露天院、首层石拱回廊、二层客房廊道与借景餐厅。 |
| E | 木廊花园旅馆 | 庭园别墅改造、灰绿木板墙、环绕檐廊、局部阳台与玻璃花园餐厅。 |

共同功能包括接待柜台、木制钥匙格、可用侧光查看登记簿的公共书写桌、临街门房、行李架、等候座椅、独立餐厅和餐厅账桌、厨房与储藏、办公室、后勤门、真实楼梯和上层客房。客房数量约 8–12 间仅为概念尺度建议，不是确认过的最终房间合同。

剧情依据是修订稿地点 I：旅馆登记簿、餐厅订单账本和门房回忆用于核对一次短暂停留；不把旅馆登记直接当作整个傍晚的不在场证明。画面纸张不写可读日期、姓名或推理答案，不增加凶案房间或新时间来源。车院使用既有暗栗红车身、黑翼子板的旅馆用车基调；车不进入历史证词。

来源：`错日证词_修订稿.docx` 的旅馆地点及片段7、`docs/mvp-demo.md`、`docs/maps/town-current/plan-data.json` 的 B08、`docs/concepts/car/round-01/design-notes.md`。使用内置 image_gen 分别生成五套，完整提示词在 `generation-prompts.json`；文件校验与目视记录在 `review-checks.json`。
