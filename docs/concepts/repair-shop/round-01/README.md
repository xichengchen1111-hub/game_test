# 修车铺五案概念图

《错日证词》修订稿地点 H 的修车铺，五个不同建筑与美术方向。每案包含外观、维修间、去顶空间示意和道具条带；图中的多视图为概念表达，后续制作需用统一布局核对门窗、车辆净空和可走动空间。

| 方案 | 名称 | 主要差异 |
| --- | --- | --- |
| A | 砖木街铺 | 两层沿街砖房、折叠车门、后翼与硬院；偏日常商住与手艺生活。 |
| B | 车马院工坊 | 一层三翼围合露天工作院，门楼、深檐与开放维修棚；偏车马院改造。 |
| C | 奶白几何车房 | 奶白阶梯女儿墙、灰绿长窗与明亮单层车间；偏克制的早期现代几何。 |
| D | 天窗铁架工坊 | 双齿天窗、砖墙与铆接铁架、玻璃分隔的客户办公室；偏小型工业。 |
| E | 旧石仓修车院 | 旧石仓、横向山墙、拱车门、木桁架与局部储物阁；偏厚重旧建筑改造。 |

共同功能：临街维修柜台、客户账本与工单查阅桌、汽车维修位、摩托车工作位、工具台、零件柜、油料与抹布储存、后办公室和后勤院。沿用 1931 年时代道具及游戏灰雾、旧木、金属和暖灯的基调。当前 B07 宅地约 18×39m；图中改造与房间布局是待选择的提案，不改变现行地图。

剧情边界：情夫拥有本镇修车铺，其历史不在场材料来自另一城市车间的记录和证词副本。图中不制造“案发当晚就在本铺工作”的新事实，不添加凶手标签、谋杀场面或可读的伪造线索。工单与纸面只示意形态，精确内容后续按剧本排版。
