## 年代与统一外观

原书明确案件发生于1931年1月，未指定现实国家。现有塔楼与住宅采用西式造型，警署参考过英国历史建筑，街道则采用1930美国城市方案；agent-memory明确这些来源不把虚构青川镇指定为英国。因此采用**原创1931西式小镇警署人物**，不把中文镇名理解成必须使用民国军警制服，也不宣称复原某个真实警队。

修订后的警服制作目标：深藏青毛呢、四枚暗铜扣的口袋外套、米白衬衣与黑领带、棕皮腰带、黑皮鞋、低帽冠有檐帽，统一原创小徽形状；衣料、钮扣和帽型一致。脸部、年龄、身材和发型分别制作，不靠同一张脸的缩放或换色区分人物。维持游戏既有人物的写实比例与略简化表面，不生成现代执法装备、现实国家徽记或不可控的可读文字。

服饰依据及取舍：

- [Greater Manchester Police Museum：二战前警服史](https://gmpmuseum.co.uk/collection-item/the-history-of-police-uniform-in-manchester-up-until-ww2/)记录毛呢警服、各地帽型差异、20世纪早期有檐帽与两次大战之间的防雨服装。其女警部分以男式上衣配长裙及系带靴为常见早期轮廓；同文指出英国普通警员敞领配领带的普及更晚。因此本轮敞领外套是跨地区的原创设计选择，不标称“1931英国标准警服”。
- [Metropolitan Police Museum：馆藏说明](https://www.met.police.uk/police-forces/metropolitan-police/areas/about-us/about-the-met/met-museums-archives/collections/)展示1923年首批有逮捕权女警的宣誓簿，支持1931背景中出现女性警员，但不能据此声称当时各地男女岗位与制服完全一致。
- [LACMA：1930年男士套装](https://collections.lacma.org/object/197076)提供邻近年代毛呢西装和宽松长裤的实物参考；律师服装为原创日常西装，不使用法庭假发或礼服。

两位女警优先保持相同外套、配色、扣子和鞋，另用宽A字过膝裙、深色袜表现年代。若实际绑定和行走采用长裤，须记录为青川原创工作制服的制作取舍；目前没有可靠依据将女警制服长裤称为1931年的普遍样式。第一轮男警外观未获接纳，不能以已生成作为保留依据。

### 身体交谈与嘴部动作的边界

对上述 **DutyOfficer 旧包** 的 Blender 4.5.9 只读导入确认：唯一动作是 `Armature|idle.001`，第 1–369 帧；网格 8930 顶点，没有 Jaw／mouth／lip 骨骼，没有 shape keys，面部相关蒙皮组仅有 `Head`。虽然存在眼球骨骼，也没有对应眼球蒙皮组。因此这个现有骨架仅追加身体 Talk，不能凭此让嘴部独立开合。其余四人的本地模型尚未取得，不能将这一具体骨架检查推广为五人均无面部支持。

当前转换工具保留源中实际存在的面部骨骼动作，但 Talk 的数值门槛只检查上半身运动；带动画的 shape keys 会被明确拒绝，尚没有对应导入支持。既有售票员的可见说话嘴部是在本地另补下颌、唇缝、口腔和 Talk 开合曲线，并非 Tripo 身体交谈动作自动提供。

取得合格的新模型和真实三段动作后，逐人检查面部支持。若仍缺嘴部变形，在各自可编辑源中按实际唇线、下颌轴和面部拓扑补局部支持，保留源 Talk 身体动作，Idle／Walk 闭嘴，Talk 小幅间歇开合；不能照搬售票员的脸部坐标或固定其下肢。明确记录修改过的面部区域与源哈希，不再声称脸部网格完全未变。正面、侧面完整动作及过渡通过后，再做静音游戏检查；没有配音时只称通用说话动作，不称语音同步。该补制目前尚未完成。
